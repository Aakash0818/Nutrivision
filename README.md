# NutriVision 🍱

### Calorie Estimation of Food Using Deep Learning

NutriVision is a deep learning-based web application that estimates food calories from uploaded food images. The project uses computer vision and machine learning techniques to classify food items and provide estimated calorie information.

---

## 🚀 Features

* Upload food images
* Food image classification using Deep Learning
* Calorie estimation
* Django-based web application
* User-friendly interface

---

## 🛠️ Tech Stack

* Python
* Django
* TensorFlow
* Keras
* OpenCV
* NumPy
* Scikit-learn
* Matplotlib

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/Aakash0818/Nutrivision.git
cd Nutrivision
```

### 2. Create virtual environment

```bash
python -m venv venv
```

### 3. Activate virtual environment

#### Windows

```bash
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python manage.py runserver
```

Open in browser:

```bash
http://127.0.0.1:8000/
```
